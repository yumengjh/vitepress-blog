## 信息安全常见术语表

| 术语         | 描述                                                 |
| ------------ | ---------------------------------------------------- |
| **肉鸡**     | 被控制的电脑                                         |
| **木马**     | 伪装成正常程序，运行后可获取系统权限                 |
| **挂马**     | 将木马放入别人网站文件中，或将木马代码嵌入正常网页中 |
| **后门**     | 入侵者在目标系统中植入特定程序以便后续持续控制       |
| **弱口令**   | 类似 `admin/123456/root` 这样的简单密码              |
| **Shell**    | 获取系统权限的命令行界面或方式                       |
| **Webshell** | 一种以网页文件形式存在的远程命令执行环境             |
| **注入**     | 通常指数据库注入                                     |
| **内网**     | 局域网，例如公司内部网络                             |
| **免杀**     | 利用技术手段规避杀毒软件的查杀                       |
| **蜜罐**     | 故意制作一个含有漏洞的系统或网站来吸引黑客           |
| **DDOS**     | 拒绝服务攻击（分布式拒绝服务攻击）                   |
| **漏扫**     | 自动化漏洞扫描工具，如：`nessus`、`xray`、`AWVS`     |
| **0day**     | 尚未被公开的通用型漏洞                               |
